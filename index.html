Star Garden: Make Ten

A short number lesson for about age 6. Objects first, then equations.

Adult guide & sources

Objectives: match numerals 0–10 to quantities; compose ten with number bonds; model addition/subtraction within ten using counters before equations.

Prerequisites: counting to ten with one-to-one correspondence; adult nearby for read-aloud if needed.

Session: about 8–12 minutes. Free, no login, no tracking. Progress stays in this browser only (localStorage). Use Reset lesson to clear.

Sources:

  • NCTM Illuminations — Ten Frame activities (composition of ten): https://illuminations.nctm.org/
  • What Works Clearinghouse / IES practice guides on early mathematics (concrete representations before symbols): https://ies.ed.gov/ncee/wwc/

This lesson is practice, not a diagnosis. It does not claim validated learning gains for every child.
